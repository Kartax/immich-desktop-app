## Before exploring

- Read the root `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/`.
- Proceed silently when either location is absent; domain-modeling workflows create them lazily.

Use the glossary's canonical vocabulary in issues, tests, and implementation. Surface any conflict with an existing ADR explicitly rather than silently overriding it.
